# 직업 거래소 1차 기준

`/pmarket list miner|farmer|fisher`로 현재 설치된 아이템의 매입 목록을 보고, `/pmarket sell <아이템ID> [수량]`으로 인벤토리에서 팔 수 있습니다. 한 번에 최대 2,304개까지 요청할 수 있으며, 인벤토리에 수량이 모자라면 거래하지 않습니다.

판매는 현재 직업과 관계없이 가능하지만, 해당 물품의 직업을 선택한 플레이어에게만 직업 판매 보너스가 붙습니다. 현재 코드의 공통 판매 보너스를 유지해 Lv.20부터 +5%, Lv.80부터 추가 +10%를 받습니다. 보너스는 묶음 총액에 반영한 뒤 원 단위로 반올림합니다.

가격은 플레이 시간당 재료 공급량을 억제하도록 낮은 기본 단가로 잡았습니다. 특히 광부는 Lv.40 광맥 채굴, Lv.50 광물 드롭 2배, Lv.70 광물 추가 드롭, Lv.90 자동 제련을 받고, 농부는 Lv.40/100 광역 수확과 Lv.50 작물 드롭 2배, Lv.90 자동 재심기를 받습니다. 어부는 Lv.30/60/100 입질 시간 감소, Lv.50 물고기 2배, Lv.40/90 잡동사니 감소, Lv.100 전설 어획을 받습니다. 따라서 50레벨 이후의 두 배 수확/어획을 고려해 단가는 두 배로 올리지 않았습니다. 광부 자동 제련은 원석과 주괴의 매입 단가를 같게 하여 처리 방식에 따른 돈 복사를 막습니다.

## 현재 판매 명령

```text
/pmarket
/pmarket list miner
/pmarket list farmer
/pmarket list fisher
/pmarket sell minecraft:diamond 4
/pmarket sell farmersdelight:cabbage 16
/pmarket sell aquaculture:atlantic_cod 3
```

이 문서의 가격은 첫 적용을 위한 시작값이며, 실제 서버에서 직업별 시간당 획득량을 확인한 뒤 조정할 수 있습니다.
